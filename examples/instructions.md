# How this vault is organized

- `Inbox/` — unsorted captures. `Projects/<name>/` — one folder per active project. `Areas/` — ongoing responsibilities. `Archive/` — done.
- Every project note has frontmatter `status: active | paused | done` and `tags: [project]`.
- Meeting notes live in `Meetings/YYYY-MM-DD <topic>.md` and are tagged `#meeting`.
- Prefer linking to existing notes over creating new ones. Never delete notes — move them to `Archive/`.
- Write in British English, concise bullet points.
